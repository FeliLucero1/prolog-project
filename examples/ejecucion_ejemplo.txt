================================================================================
EJEMPLOS DE EJECUCIÓN - SISTEMA DE COMPRA DE JUGADORES
================================================================================

Para ejecutar estos ejemplos, carga el sistema en SWI-Prolog:

    swipl
    ?- [src/sistema_compras].

================================================================================
EJEMPLO 1: Verificar si un equipo puede firmar a un jugador
================================================================================

?- puede_firmar('Real Madrid', 'Kylian Mbappé').
false.

?- puede_firmar('Real Madrid', 'Robert Lewandowski').
true.

?- puede_firmar('Barcelona', 'Erling Haaland').
true.

?- puede_firmar('Barcelona', 'Kylian Mbappé').
false.

Explicación: Mbappé y Haaland exceden el presupuesto disponible.

================================================================================
EJEMPLO 2: Obtener recomendaciones para un equipo
================================================================================

?- recomendar('Barcelona', Jugador).
Jugador = 'Erling Haaland' ;
Jugador = 'Bukayo Saka' ;
Jugador = 'Robert Lewandowski' ;
Jugador = 'Karim Benzema' ;
Jugador = 'Cristiano Ronaldo' ;
Jugador = 'Rúben Dias' ;
Jugador = 'Marquinhos' ;
Jugador = 'Alessandro Bastoni' ;
Jugador = 'Ronald Araújo' ;
Jugador = 'David Alaba' ;
Jugador = 'Theo Hernández' ;
Jugador = 'Sergio Ramos' ;
false.

Explicación: El sistema ordena jugadores por rendimiento (goles + asistencias)

y tiene presupuesto de 150M. Mbappé (180M) excede el presupuesto.

EJEMPLO 4: Listar todos los jugadores disponibles
================================================================================

?- jugadores_disponibles('Manchester City', Lista).
Lista = ['Kevin De Bruyne', 'Bruno Fernandes', 'Pedri', 'Jude Bellingham', 
         'Federico Valverde', 'Rodri', 'Gavi', 'Eduardo Camavinga', 
         'Jamal Musiala', 'Rúben Dias', 'Marquinhos', 'Alessandro Bastoni', 
         'Ronald Araújo', 'Theo Hernández', 'David Alaba', 'Sergio Ramos'].

Explicación: Manchester City necesita mediocampista y defensa (no delanteros),
y tiene presupuesto de 300M. Solo aparecen jugadores de las posiciones necesitadas.

EJEMPLO 7: Encontrar combinación óptima
================================================================================

?- combinacion_optima('Real Madrid', Lista).
Lista = ['Robert Lewandowski', 'Kevin De Bruyne'].

Explicación: Esta combinación maximiza el rendimiento total (36 + 32 = 68)
respetando el presupuesto de 200M. 
Costo: 25 + 80 = 105M <= 200M ✓
Rendimiento: (30+6) + (12+20) = 68 puntos

Otras combinaciones válidas:

?- combinacion_valida(['Robert Lewandowski', 'Pedri'], 'Real Madrid').
true.
% Costo: 25 + 100 = 125M <= 200M ✓
% Rendimiento: 36 + 20 = 56 puntos

?- combinacion_valida(['Erling Haaland', 'Pedri'], 'Real Madrid').
false.
% Costo: 150 + 100 = 250M > 200M ✗

?- combinacion_valida(['Jude Bellingham', 'Ronald Araújo'], 'Real Madrid').
false.
% Real Madrid necesita delantero y mediocampista, pero esta combinación
% solo tiene mediocampista (Bellingham) y defensa (Araújo) ✗

EJEMPLO 8: Verificar restricciones de extranjeros
================================================================================

?- es_extranjero('Kylian Mbappé', 'Real Madrid').
true.

?- es_nacional('Pedri', 'Barcelona').
true.

?- contar_extranjeros(['Erling Haaland', 'Pedri', 'Ronald Araújo'], 'Real Madrid', Cantidad).
Cantidad = 2.

Explicación: Haaland (noruega) y Araújo (uruguay) son extranjeros para Real Madrid.
